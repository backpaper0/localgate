# Implementation Plan

- [ ] 1. 共有ヘルパーの実装

- [ ] 1.1 サーバーURL解決ロジックの実装
  - `--server` フラグ値 → `LOCALGATE_SERVER` 環境変数 → デフォルト値 `http://localhost:9000` の優先順位でサーバーURLを返す関数を `cmd/` パッケージ内に実装する
  - フラグ値が空でない場合はその値を最優先で返す
  - フラグ値が空かつ `LOCALGATE_SERVER` 環境変数が設定されている場合は環境変数の値を返す
  - どちらも未設定の場合はデフォルト値を返す
  - _Requirements: 4.1, 4.2, 4.3, 4.4, 4.5_

- [ ] 1.2 API通信で使用する共通データ型の定義
  - `POST /services` リクエストボディの型（name・target フィールド）を定義する
  - サービスエントリ（name・target）の型を定義する
  - `GET /services` レスポンスボディの型（services 配列）を定義する
  - APIエラーレスポンス（error フィールド）の型を定義する
  - _Requirements: 1.1, 2.1, 3.1_

- [ ] 2. サービス登録コマンドの実装

- [ ] 2.1 (P) registerコマンドの骨格とフラグ定義
  - cobra で `register` サブコマンドを定義し、`rootCmd` に登録する
  - `<name>` と `<target>` の2つの位置引数を必須とし、不足時には使い方を自動表示する
  - `--server` フラグを定義し、デフォルト値は空文字列とする
  - `init()` 内でフラグと `AddCommand` の登録を行う
  - _Requirements: 1.4_

- [ ] 2.2 (P) 管理APIへの登録リクエストとレスポンス処理
  - 1.1のURL解決ヘルパーでサーバーURLを取得し、`POST /services` にJSONリクエストを送信する
  - HTTP 201 レスポンス受信時は登録完了メッセージを標準出力に表示して終了コード0で終了する
  - HTTP 4xx/5xx レスポンス受信時はサーバーから返されたエラーメッセージを標準エラー出力に表示して終了コード1で終了する
  - 接続失敗（`net/http` エラー）時は接続エラーを標準エラー出力に表示して終了コード1で終了する
  - _Requirements: 1.1, 1.2, 1.3, 1.5_

- [ ] 3. サービス解除コマンドの実装

- [ ] 3.1 (P) unregisterコマンドの骨格とフラグ定義
  - cobra で `unregister` サブコマンドを定義し、`rootCmd` に登録する
  - `<name>` の1つの位置引数を必須とし、不足時には使い方を自動表示する
  - `--server` フラグを定義する
  - _Requirements: 2.5_

- [ ] 3.2 (P) 管理APIへの解除リクエストとエラー処理
  - 1.1のURL解決ヘルパーでサーバーURLを取得し、`DELETE /services/{name}` にリクエストを送信する
  - HTTP 204 レスポンス受信時は解除完了メッセージを標準出力に表示して終了コード0で終了する
  - HTTP 404 レスポンス受信時はサービスが見つからない旨のエラーを標準エラー出力に表示して終了コード1で終了する
  - HTTP その他4xx/5xx レスポンス受信時はサーバーから返されたエラーメッセージを標準エラー出力に表示して終了コード1で終了する
  - 接続失敗時は接続エラーを標準エラー出力に表示して終了コード1で終了する
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 2.6_

- [ ] 4. サービス一覧表示コマンドの実装

- [ ] 4.1 (P) listコマンドの骨格とフラグ定義
  - cobra で `list` サブコマンドを定義し、`rootCmd` に登録する
  - 位置引数を受け付けないよう設定し、余分な引数が渡された場合は使い方を表示する
  - `--server` フラグを定義する
  - _Requirements: 3.1_

- [ ] 4.2 (P) 管理APIへの一覧取得リクエストと出力処理
  - 1.1のURL解決ヘルパーでサーバーURLを取得し、`GET /services` にリクエストを送信する
  - HTTP 200 レスポンス受信時は登録済みサービスのname・target を標準出力に一覧表示して終了コード0で終了する
  - レスポンスのサービスリストが空の場合は「登録済みサービスはありません」等のメッセージを標準出力に表示して終了コード0で終了する
  - HTTP 4xx/5xx レスポンス受信時はエラーメッセージを標準エラー出力に表示して終了コード1で終了する
  - 接続失敗時は接続エラーを標準エラー出力に表示して終了コード1で終了する
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 3.5_

- [ ] 5. テストの実装

- [ ] 5.1 共有ヘルパーのユニットテスト
  - フラグ値が指定されている場合にその値が返されることを検証する
  - フラグ値が空で `LOCALGATE_SERVER` が設定されている場合に環境変数の値が返されることを検証する
  - どちらも未設定の場合に `http://localhost:9000` が返されることを検証する
  - フラグ値が環境変数より優先されることを検証する
  - _Requirements: 4.1, 4.2, 4.3, 4.4, 4.5_

- [ ] 5.2 各コマンドの統合テスト
  - `net/http/httptest` でモックサーバーを立て、各コマンドのHTTPリクエストが正しいメソッド・パス・ボディで送信されることを検証する
  - registerコマンド: 201レスポンス時の標準出力・終了コード、4xx/5xx時の標準エラー出力・終了コード、接続失敗時のエラー表示を検証する
  - unregisterコマンド: 204、404、5xx レスポンス時の各出力・終了コード、接続失敗時のエラー表示を検証する
  - listコマンド: サービスあり一覧表示、サービスなしメッセージ、エラー時の標準エラー出力を検証する
  - _Requirements: 1.2, 1.3, 1.5, 2.2, 2.3, 2.4, 2.6, 3.2, 3.3, 3.4, 3.5_
