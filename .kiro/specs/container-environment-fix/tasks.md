# 実装計画

- [x] 1. サーバの自己ホスト名機能を実装する
- [x] 1.1 ServerConfig と ProxyServer を拡張して自己ホスト名セットを管理する
  - `ServerConfig` に自己ホスト名を指定するためのフィールドを追加する
  - `ProxyServer` が内部に自己ホスト名セット（`map[string]struct{}`）を保持するようにする
  - `NewProxyServer` の初期化処理で「`localhost`」を常にセットに追加し、設定値が空でなければそれも追加する（大文字・小文字を小文字に正規化してから格納する）
  - _Requirements: 1.4, 2.1, 2.2, 2.3_

- [x] 1.2 ServeHTTP のルーティング判定に自己ホスト名チェックを追加する
  - タスク 1.1 の完了後に実施する（`selfHostnames` の存在が前提）
  - `ServeHTTP` で、既存のサブドメイン抽出の前に Host ヘッダからポート番号を除去して小文字に正規化する処理を追加する
  - 正規化したホスト名が自己ホスト名セットに含まれる場合は管理APIへ処理を委譲し、以降の処理を行わない
  - 自己ホスト名に一致しない場合は、これまで通りサブドメイン抽出によるプロキシ判定に進む
  - _Requirements: 1.1, 1.2, 1.3, 2.4, 2.5_

- [x] 2. (P) start コマンドに --hostname フラグを追加する
  - タスク 1.1 の完了後に実施する（タスク 1.2 とは異なるファイルを変更するため並行実施が可能）
  - `start` サブコマンドに `--hostname` フラグを定義し、デフォルト値は空文字列とする
  - フラグで受け取った値をサーバ設定の自己ホスト名フィールドに渡す
  - _Requirements: 2.2, 2.3_

- [x] 3. テストを追加する
- [x] 3.1 (P) ProxyServer の自己ホスト名初期化に関するユニットテストを追加する
  - タスク 1 の完了後に実施する（タスク 3.2 とはテストファイルを分けて並行実施が可能）
  - ホスト名未指定時に `localhost` のみが自己ホスト名として扱われることを確認するテストを追加する
  - `--hostname=localgate.test` 指定時に `localhost` と `localgate.test` の両方が自己ホスト名として扱われることを確認するテストを追加する
  - 大文字を含むホスト名（例: `Localgate.TEST`）が正規化されてセットに格納されることを確認するテストを追加する
  - _Requirements: 1.4, 2.1, 2.2, 2.3, 2.4_

- [x] 3.2 (P) コンテナ環境を想定した統合テストを追加する
  - タスク 1・2 の完了後に実施する（タスク 3.1 とは別観点のテストのため並行実施が可能）
  - `--hostname=localgate.test` 設定時に `localgate.test:9000` へのリクエストが管理API（POST /services、GET /services）へ正しくルーティングされることを確認するテストを追加する
  - `--hostname=localgate.test` 設定時に `foo.localgate.test:9000` へのリクエストが登録済みサービスへプロキシされることを確認するテストを追加する
  - `localhost:9000` へのリクエストが引き続き管理APIへルーティングされることを確認するテストを追加する（後方互換性の検証）
  - `--hostname` 未設定時に `localgate.test:9000` が管理APIではなくプロキシ判定されることを確認するテストを追加する
  - _Requirements: 1.1, 1.2, 2.3, 3.1, 3.2, 3.3, 3.4_
