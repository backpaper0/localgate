# Product Overview

localgate はローカル開発環境向けの動的リバースプロキシ。サブドメインベースのルーティングにより、複数のローカルHTTPサービスを単一エンドポイントから利用できる。

## Core Capabilities

- **サブドメインルーティング**: `foo.localhost:9000` → `localhost:3000` のようにHostヘッダのサブドメインでバックエンドを特定し転送
- **動的サービス管理**: 再起動不要のHTTP APIでサービスの登録・解除が可能。`register` / `unregister` / `list` サブコマンドでCLIからも操作できる
- **管理API / プロキシの自動判定**: サブドメインなし(例: `localhost:9000`)へのリクエストを管理APIとして処理、サブドメインありをプロキシとして処理
- **コンテナ環境対応**: `--hostname` オプションで追加の自己ホスト名を指定可能。コンテナ内では `localgate.test` 等のカスタムホスト名でも管理APIにアクセスできる

## Target Use Cases

- ローカル開発環境で複数サービスを単一ポートで公開
- マイクロサービス開発時のサービスゲートウェイ
- コンテナ環境での簡易リバースプロキシ

## Value Proposition

設定ファイル不要・再起動不要で動的にサービスを追加できる軽量ゲートウェイ。Goの標準ライブラリを最大限活用し、依存を最小限に抑えたシンプルな実装。
